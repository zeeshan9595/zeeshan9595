## Working principles

- Validate on data that would have been available at the decision date.
- Benchmark complex models against simple, transparent alternatives.
- Translate model outputs into thresholds, costs and operational consequences.
- Treat data quality, leakage and limitations as part of the analysis—not as footnotes.
- Distinguish observed results from assumptions and scenario analysis.
